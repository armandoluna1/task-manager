# Daylist

A small, mobile-friendly task manager written in HTML, CSS, and JavaScript.

## Run on your computer

Download and extract the project, then open index.html in your browser. For development, you can also run `python3 -m http.server 8000` inside the project folder and visit http://localhost:8000.

## Using Daylist

Enter a task name and optionally pick a due date. Click **Add task** or press Enter. Check the box beside a task to mark it complete. **Edit** lets you rename it or change or remove its due date. **Delete** removes it.

Combine **All**, **Active**, or **Completed** with a due-date filter. Overdue shows unfinished tasks dated before today. Dates use your local calendar. Tasks are saved in the browser on the device and site where you entered them. Clearing site data removes them.

## Upload and publish on GitHub

1. Create a public repository named task-manager.
2. On the repository page, choose **uploading an existing file** or **Add file → Upload files**.
3. Upload index.html, style.css, app.js, and README.md directly into the repository root. Commit the changes.
4. To publish the app, open **Settings → Pages**. Select **Deploy from a branch**, select your default branch (usually main), choose **/(root)**, and save.
5. When deployment finishes, open the website link shown on the Pages screen.
